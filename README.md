# GHANA EXPLORER — HTML + CSS edition

This edition contains static, multi-page HTML and one shared CSS stylesheet. It is intentionally HTML/CSS only: no JavaScript, Firebase, accounts, live map, admin dashboard, forms, search or uploads are included.

## Pages
- `index.html` — home page
- `regions.html` — all 16 regions
- `regions/*.html` — 16 dedicated regional pages
- `destinations.html` — destination inspiration
- `culture.html` — culture overview
- `food.html` — Ghanaian food overview
- `travel.html` — general travel planning reminders
- `about.html` — project information
- `styles.css` — shared responsive styling

## Run
Open `index.html` in a browser, or use VS Code with the free Live Server extension. All page navigation uses ordinary HTML links.

## Edit
Change text in the relevant `.html` page. Change colours, typography and layouts in `styles.css`. Destination photos are sample remote Unsplash images; replace them with images you own or have permission to use.

## Accuracy note
Regional capitals are provided as starter reference information. Destination descriptions are general editorial summaries. Confirm current access, fees, opening times, safety, travel requirements and local conditions with official or local sources before travelling. Some destination content is illustrative and not a verified live directory.

## Important limitation
Because this version contains only HTML and CSS, it cannot implement user accounts, favourites that persist, interactive map behaviour, Firebase data, media uploads or an admin dashboard. Those require JavaScript and a backend/service such as Firebase.
